Set up

Install once. Connect your assistant. Your wallet creates itself.

Prepare for launch ↗

Before you start

Prepare now. Use hosted tools at launch.

Packages are published. Hosted actions open with the token and subscription launch; until then, actions are limited to the Oak team. Read calls such as find_token remain available.

Default human confirmation is part of the prepared 0.1.1 release candidate. The currently published 0.1.0 packages predate that change. Update at launch before funding a wallet or enabling actions.

Keep your assistant open on your computer. A website visit does not connect a wallet.

1. Install 2. Connect 3. Wallet 4. Fund 5. Ask

1. Install Oak

Use Node.js 22 LTS (22.12 or later within version 22). In your terminal:

npm install -g @oakagentkit/addon

The add-on includes the core package. Both are published; installing does not unlock hosted access before launch.

Prefer to ask your agent? Copy this prompt

Set up Oak for this AI agent using Node.js 22. Install @oakagentkit/addon and connect the local MCP command oak mcp. Call account and tell me the public wallet address and network. When hosted access opens, ask me to fund ETH for network fees and USDG, then re-check balances. Do not run oak init or oak export, read wallet/key files, or ask for keys or recovery words. Explain public identity registration and recurring subscription costs; get my approval before either.

2. Connect your assistant

Choose your client, add Oak, then start a fresh session. MCP is a connection for AI tools; the local command is oak mcp.

Claude Code

Run in your terminal after installing Oak.

claude mcp add oak -- oak mcp
Codex

Add to your Codex MCP configuration.

[mcp_servers.oak]
command = "oak"
args = ["mcp"]
Gemini

Add to your Gemini MCP settings.

{"mcpServers":{"oak":{"command":"oak","args":["mcp"]}}}
Cursor

Add to your Cursor MCP configuration.

{"mcpServers":{"oak":{"command":"oak","args":["mcp"]}}}
Grok / other MCP hosts

Use a host that supports local stdio MCP servers.

{"mcpServers":{"oak":{"command":"oak","args":["mcp"]}}}

3. Your wallet is automatic

First MCP or CLI wallet use creates it on your computer. Later runs reuse it. Ask your agent:

Call account. Show only my public wallet address and network. Do not send a transaction.

Before hosted access opens, you can display the local public address in your terminal:

oak address

Your private key never leaves your computer. Oak cannot recover a lost key. Backups are optional: oak backup gives guidance. Run oak init or oak export only in your own terminal, never through the agent. Never paste a key or recovery words into chat.

4. Fund when access opens

After updating to the launch release, send ETH for network fees and USDG for subscription payments to the public wallet address. Use the network it reports: Robinhood Chain mainnet is 4663. Then ask:

Re-check balances and show the ETH and USDG amounts on my selected network. Do not register or subscribe yet.

Read tools need no identity or subscription once hosted access opens. Paid actions need both a public agent identity and an active subscription.

Approve identity and subscription separately

ERC-8004 is a public agent identity. Registration publishes a profile and costs ETH for gas. Linking an existing identity needs no gas; an external owner signs in their own terminal.

Explain oak_setup registration or linking and its cost. Ask for my approval before proceeding. Then call account, explain the available plan and recurring cost, and ask separately before oak_subscribe.

At launch, the curve phase offers only no-hold at 12.333333 USDG per 30 days. After graduation, both plans wait through warmup. When ready, the holder plan costs 9 USDG per 30 days plus the required $OAK holding and one-time sign-up burn.

While oak mcp runs, active subscriptions auto-renew when three days or fewer remain. Prepay is capped at 90 days ahead. Cancelling with oak cancel ends access immediately and forfeits remaining paid days.

5. Make your first request

Start with a read after hosted access opens:

Call account, balances and positions. Show my network, balances and subscription status in plain English. Do not send any transactions.

Then try a quote, without sending a transaction:

Find USDG and ETH with find_token. Quote 10 USDG (10000000 base units) to ETH with slippageBps 50. Explain the expected and minimum output. Do not swap.

For a later action, inspect the preview, confirm the exact action, then let the local wallet sign. Built approvals are exact. Simulations exclude gas and cannot prove external settlement or whether a token can later be sold.

Run oak init --recover in your own terminal to restore an exported private key or legacy 24-word backup on a new computer. To replace an existing wallet, use oak init --recover --replace; Oak preserves an encrypted backup and asks you to confirm the recovered address. Never enter recovery words in an agent chat, arguments, environment variables or MCP tools.

New automatic wallets work with a persistent OS keychain or an owner-only random file key. Existing passphrase wallets are unchanged and still require terminal unlock. Never pass a passphrase through MCP, argv or environment variables. See headless wallet guidance for legacy migration options.

Mainnet uses https://api.oakagentkit.org by default. Override it with oak config set OAK_SERVER_URL <https-url> or OAK_SERVER_URL; testnet requires an explicit matching service URL. Configure the published deployment addresses and your RPC before starting MCP.

Transactions reported as “awaiting finality” keep their signed journal evidence until final. New actions wait for reconciliation; a removed receipt is recovered at the same nonce, or an expired call has its nonce replaced with a zero-value self-transfer. Do not delete journal files to force a retry. If a sequence stops after approval, the error lists token, spender, base-unit amount and chain. The next action previews and revokes the remaining allowance before new work; keep ETH available for cleanup. You can also call approve(spender, 0) on that token in your own wallet on the named chain.

Price notes require an ETH/USD pool observation no older than 30 minutes and a current 30-minute OAK trade window. Missing, future-dated or stale sources refuse note issuance with a retry explanation; an old Uniswap observation extrapolated by observe(0) does not qualify.
