Set up

Start setup

Install once. Connect your assistant. Your wallet creates itself.

Before you start

Install, connect and ask.

$OAK is live. Oak is free. Reads work straight away. Actions need a verified ERC-8004 agent ID and your yes or no in chat. Call account to see where your setup stands. Official $OAK address: 0x6511c233790Ec10f7d673c64DC82C3F941D57828. Pons page: https://ponsfamily.com/launchpad/0x6511c233790ec10f7d673c64dc82c3f941d57828.

Version 0.3.0 makes Oak free to use on Robinhood Chain, with approval in chat, an optional daily spending limit in USD, oak connect, Upoch reads. Agent 1's public tracker is being prepared. Run oak --version to see the version you have.

Keep your assistant open on your computer. A website visit does not connect a wallet.

1. Install 2. Connect 3. Wallet 4. Fund 5. Ask

1. Install Oak

Use Node.js 22.12.0 or newer. In your terminal:

npm install -g @oakagentkit/addon

The add-on includes the core package. Check oak --version before funding or using actions.

Prefer to ask your agent? Copy this prompt

Set up Oak for this AI agent using Node.js 22.12.0 or newer. Install @oakagentkit/addon and connect the local MCP command oak mcp. Call account and tell me the public wallet address and network. If the wallet needs it, ask me to fund a little ETH for network fees, then re-check balances. Do not run oak init or oak export, read wallet/key files, or ask for keys or recovery words. Explain public agent ID registration and its cost; get my yes before registering.

2. Connect your assistant

Choose your client and run its command in your terminal after installing Oak. MCP is a connection for AI tools; Oak configures the local oak mcp command.

These connect Claude Code, Codex, Cursor, Gemini CLI and Grok respectively. Claude Code must be installed. Cursor connects the current project, so run its command from that project's folder. The others connect your user account by default. Restart your app afterward. If Oak finds a conflicting entry, it explains how to fix it without overwriting it.

Claude Code 
oak connect claude
Codex 
oak connect codex
Cursor 
oak connect cursor
Gemini 
oak connect gemini
Grok 
oak connect grok

3. Your wallet is automatic

Ask your agent: “What is my Oak wallet address?” Oak creates the wallet on first use. Check the address and that the network is Robinhood Chain. Your private key stays on your computer. Never give it or a recovery phrase to an agent. Oak cannot recover a lost key. For backup guidance, run oak backup in your own terminal; run oak export only in your own terminal, never through the agent, and keep the exported key offline.

Ask your agent:

Call account. Show only my public wallet address and network. Do not send a transaction.

You can also display the local public address in your terminal:

oak address

Your private key never leaves your computer. Oak cannot recover a lost key. Backups are optional: oak backup gives guidance. Run oak init or oak export only in your own terminal, never through the agent. Never paste a key or recovery words into chat.

4. Fund the wallet

Send a little ETH on Robinhood Chain for network fees, plus the money you want to use: ETH or USDG. Then ask your agent to check your balance.

If your money is on Base, your agent can prepare a Relay bridge to this wallet on Robinhood Chain. You can review the amount and fees before saying yes.

Base bridge-in uses the default RPC; you do not need to set one up. Ask the agent to check your balance after funding.

Use the network your wallet reports: Robinhood Chain mainnet is 4663. Then ask:

Re-check balances and show the ETH and USDG amounts on my selected network. Do not register or send a transaction yet.

Agent identity and approval in chat

Ask what you want to do. Reads work without an agent ID. For actions, Oak can prepare a public ERC-8004 agent ID registration after funding. The agent shows the public profile and network fee, then waits for your one approval before registration. You can instead link an existing ID; if another wallet owns it, its owner signs in their own terminal.

The agent asks once whether you want an optional daily spending limit in USD. Skipping leaves no limit; you can set or change it later in chat.

For an action, the agent calls a listed action tool or oak_prepare with {"name":"<tool>","arguments":{...}}. Oak builds and simulates it without signing, returning a summary, actionId and UTC expiry. The agent shows the summary and waits for your yes or no. After a yes, it calls oak_execute {"actionId":"<actionId>"}. Oak checks the action again and signs locally. Review the amounts, fees, permissions and warnings before deciding.

Explain oak_setup registration or linking and its cost. Show the public profile and network fee, then ask for my approval before registering.

Review the summary before saying yes or no in chat. You can ask to change the optional daily spending limit later.

5. Make your first request

Start with a read:

Call account, balances and positions. Show my network, balances and setup status in plain English. Do not send any transactions.

Then try a quote, without sending a transaction:

Find USDG and ETH with find_token. Quote 10 USDG (10000000 base units) to ETH with slippageBps 50. Explain the expected and minimum output. Do not swap.

More first prompts to paste:

  • What can you do with Oak? Group the tools by project.

  • Show my Oak wallet address and balances. Do not send anything.

  • Quote a swap of 5 USDG to ETH with the best route. Show the preview and do not swap yet.

  • Lend 10 USDG on Priors. Show me the preview before anything is signed.

  • Deposit 10 USDG into a Steakhouse vault. Show me the preview first.

  • Show my open positions across every project.

One click selects a whole command or prompt. Then copy it: Cmd or Ctrl + C, or long-press on a phone.

For a later action, inspect the preview and say yes or no in chat. After a yes, oak_execute checks the action again before local signing. Built approvals are exact. Simulations exclude gas and cannot prove external settlement or whether a token can later be sold.
