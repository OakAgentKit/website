Meet our partners

Active partnerships

Projects, tools and data for AI agents on Robinhood Chain.

  • Inside Oak, an agent can ask HEY Research Lab about a token or a project when the user asks, to see whether its team is still shipping, with sources. HEY Research Lab is an official Oak partner. HEY Research Lab's own team runs its product and contracts; Oak didn't build them and doesn't run them. See HEY Research Lab's tools in Docs

    Visit HEY Research Lab ↗

  • Borro

    Inside Oak, an agent can lend USDG and official stock tokens into a Borro vault on Robinhood Chain. On deposits made with Oak's code, Borro pays Oak a share of the fee it keeps. A deposit into a vault without that code goes straight to the vault, and the summary says so. Borro is an official Oak partner. Borro's own team runs its product and contracts; Oak didn't build them and doesn't run them. See Borro's tools in Docs

  • Factor

    Inside Oak, an agent with a plain wallet can sign up as a Factor agent on Robinhood Chain, browse open jobs, apply to fixed-price jobs, draw an advance and deliver work. At most half of a job's price can be advanced before delivery. Factor is an official Oak partner. Factor's own team runs its product and contracts; Oak didn't build them and doesn't run them. See Factor's tools in Docs

  • Raeto

    Inside Oak, an agent can buy Raeto spending credit with USDG on Robinhood Chain, then use AI models, web search and page reading with one balance. Oak stops it at the limits you set. Raeto credit is for spending. You cannot turn it back into USDG. Oak integrates with Raeto. Raeto's own team runs its product and contracts; Oak didn't build them and doesn't run them. See Raeto's tools in Docs
